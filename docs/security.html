Security

This article describes how XenMan protects connections and stored credentials.

HTTPS certificate

XenMan serves its web interface over HTTPS only. On first start it creates a self-signed certificate, so browsers show a warning once.

To use a certificate from your own certificate authority, go to Settings > Appliance > HTTPS Certificate and upload PEM files (certificate, key and optional intermediate certificates) or a PFX file. XenMan checks that the key matches the certificate and switches over without a restart. Administrators see a notice 30 days before the certificate expires.

Note: For the Docker container, place cert.pem and key.pem, or cert.pfx, in the data directory before you start XenMan.

XenServer host certificates

XenServer hosts use self-signed certificates. XenMan checks them in the same way that SSH checks host keys:

  • When you add a pool, you compare and trust the coordinator's certificate fingerprint.
  • XenMan learns the certificates of the other hosts from the pool over this verified connection.
  • XenMan connects to a host only if it presents a trusted certificate. If a certificate changes unexpectedly, XenMan refuses the connection, records it in the audit log, notifies administrators by email and shows a warning.

Trusted certificates are listed under Settings > Pools > Host certificates. An administrator can accept a certificate that was renewed on purpose.

Stored passwords

XenMan stores pool and mail server passwords encrypted with AES-256-GCM. On the appliance, the key is kept outside the data directory and protected by the appliance's own system key (and its TPM, if available). A copy of the data directory alone cannot be decrypted.

Important: If you restore a data directory onto another appliance, XenMan marks the pool passwords as unreadable. Enter them again under Settings > Pools.

Audit log

XenMan records sign-ins and every change in an audit log, with the user, the time and the result. Administrators can view it under Audit Log and forward events to a syslog server under Settings > Mail & Logging.
