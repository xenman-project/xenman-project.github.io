Install XenMan

You can install XenMan as an appliance on your XenServer pool or as a Docker container. The appliance is recommended: it includes signed in-place updates and automatic Debian security updates.

Install the appliance

To install the appliance:

  1. Download xenman-appliance-v1.0.5.xva from the latest release. Compare its SHA-256 checksum with the value in the release notes.
  2. Import the file into your pool, either in XenCenter with File > Import or on the command line:
    xe vm-import filename=xenman-appliance-v1.0.5.xva
  3. Start the VM. The console shows the IP address the appliance received by DHCP.
  4. Open https://<address>/ in your browser and accept the self-signed certificate once.
  5. Sign in as admin with the password admin. XenMan asks for a new password before anything else opens.

Note: Without DHCP, sign in on the VM console as root with the password xenman. You must change the password, then a menu opens where you configure the network.

Appliance console menu

The console menu shows and configures the network, tests connectivity, restarts XenMan or the appliance, resets an administrator's password or two-factor sign-in, and switches SSH access on or off. SSH is off by default.

Change the network settings

In XenMan, go to Settings > Appliance > Network to set DHCP or a static address, DNS servers and the host name. Changes are applied on probation: if you do not confirm the new address within 90 seconds, the previous settings return.

Install with Docker

To run XenMan as a container:

  1. Download the Compose file:
    curl -O https://raw.githubusercontent.com/xenman-project/xenman/main/docker-compose.yml
  2. Start the container:
    docker compose up -d
  3. Open https://<host>:3001 and sign in as admin / admin. Choose a new password when prompted.

Data persists in the xen-data volume. To pin a release, use an image tag such as ghcr.io/xenman-project/xenman:v1.0.5.

Next steps
