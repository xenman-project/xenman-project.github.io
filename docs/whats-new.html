What's new

This article describes the new features and fixes in recent XenMan releases. For the complete list, see the changelog.

XenMan 1.0.5

Released November 27, 2026 · Beta

Snapshot schedules

You can now take VM snapshots on a schedule: hourly, daily or weekly, keeping 1 to 10 snapshots per VM. For more information, see Snapshot schedules.

Recent Tasks

A Recent Tasks panel is docked at the bottom of every view. It lists running and finished tasks of the last 24 hours, including tasks started by XenCenter and other clients.

Configure Updates

You can now set the update channel, automatic synchronization and a proxy server per pool. For more information, see Configure updates.

Bulk VM actions

You can now start, shut down or reboot several VMs at once from the VMs tab of a pool or host.

VM Tools details

The VM overview shows the virtualization mode and the versions of the XenServer VM Tools and drivers.

Microsoft Entra ID sign-in

Users can sign in with their Microsoft account. Their role comes from Entra ID app roles, and MFA is handled by Entra ID. For more information, see Sign in with Microsoft Entra ID.

Updates on single-host pools

On a pool with one host, the update can shut down running VMs and start them again afterwards.

Security

This release includes hardening from a security review. The XenServer session stays on the server, host restart and shutdown are restricted to administrators, and requests from other sites are refused.

XenMan 1.0.4

Released November 16, 2026 · Beta

Pools behind NAT

You can now manage pools at other sites that are reached through NAT, including consoles and performance graphs. For more information, see Pools at other sites.

Two-factor sign-in

Users can protect their account with an authenticator app. Administrators can require it. For more information, see Two-factor sign-in.

PVS-Accelerator

You can now manage PVS read caching per VM and the cache per PVS site and server.

iSCSI target scan

When you create an iSCSI SR, XenMan lists the target's IQNs and LUNs, so you no longer type them.

New pool coordinator

When you put the pool coordinator into maintenance mode, XenMan offers a new coordinator, as XenCenter does.
